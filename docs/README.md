<div class="lp-head">
<div class="no">04</div>
<h2>关于</h2>
</div>
<div class="lp-about">
<div>
<p>计算机专业在读。日常在写代码、写小说，把两者的流程互相借。</p>
<p>写作上的问题（状态管理、一致性校验、可复现的验收）拿去改软件工程，反过来也一样——<strong>长篇小说的连贯性问题，本质是一个数据一致性问题</strong>。</p>
<p>这也是「徽写」的起点：不是让模型写得更华丽，而是让一本写到两百章的书，仍然记得第三章那把钥匙在谁手里。</p>
